# Royal Indian Wedding Invitation — Rohit & Vrushali

React + Vite + Tailwind CSS + Framer Motion + Lucide. All artwork, code and copy are original.

## Run

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production build in /dist
npm run preview    # serve the production build
```

Add `?open` to the URL (e.g. `/?open`) to skip the opening gate while testing.

## Change the invitation (one file)

Everything lives in **`src/config/weddingData.js`**: names, parents, date, venue, events, story,
hotels, gallery, video, contacts, WhatsApp number, footer text. Sections never hard-code details.

* **WhatsApp RSVP number** → `rsvp.whatsappNumber`
* **Backend later** → set `rsvp.endpoint`; RSVPs are POSTed as JSON (WhatsApp still opens).
  The payload is built in `src/utils/submitRsvp.js`.
* **Pre-wedding video** → drop an mp4 in `public/video/` and set `video.src`, or set `video.youtubeId`.
* **Google Maps** → directions links are built from venue/address; set `wedding.mapUrl` for an exact share link.

## Replace the demo artwork with real photographs

The demo ships with original illustrations in `public/images/*.svg` (generated by
`scripts/make-art.mjs`, optimised with svgo via `npm run art`).
To use photographs, copy `.jpg`/`.webp` files into `public/images/` and change the paths in
`weddingData.js` (e.g. `image: '/images/groom.jpg'`). Image tags already use lazy loading,
`object-cover` and fixed aspect ratios, so photos will crop cleanly:

| Slot | Suggested ratio |
| --- | --- |
| groom / bride portraits | 4:5 |
| event, hotel and story images | 4:3 |
| gallery | each item has its own `ratio` in the config |
| video thumbnail | 16:9 |
| cover (`cover-bg.svg`, `cover-bg-mobile.svg`) | 16:9 desktop, 9:16 mobile (edit `InvitationCover.jsx`) |

## Structure

```
src/
  config/weddingData.js      all demo content
  components/                one file per section + ScratchCard, FallingPetals, SiteMenu
  components/art/Decor.jsx   Ganesh, mandala, ornament divider, corner flourishes, marigold border
  components/ui/             Reveal (scroll animation), SectionHeading
  hooks/                     useCountdown, useScrollLock
  utils/                     date/link helpers, RSVP → WhatsApp message
  styles/global.css          palette variables, buttons, form fields, textures
scripts/                     artwork generator
```

Palette variables (`--royal-maroon`, `--antique-gold`, …) are defined in `global.css`; matching RGB
channel variables let Tailwind opacity utilities such as `bg-maroon/60` work.
`prefers-reduced-motion` is respected (no petals, instant reveals, simple gate fade).
